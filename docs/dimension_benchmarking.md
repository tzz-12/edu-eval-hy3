# 评测维度权威性溯源调研

> 目的：验证 EduEval 8+1 维度设计的权威性——每个维度是否有权威依据，权威体系怎么定义维度，我们是否有结构性缺口。
> 调研对象：① EQuIP Rubric for Science（Achieve/NSTA，2014，美国权威教学材料评规）；② Danielson Framework for Teaching 2022（美国最广泛使用的教学评价框架，4 领域 22 组件）；③ 教育部"一师一优课、一课一名师"官方评价量表（上海市级量表、杨凌/汉源推优标准）；④ LLM 教学设计评测论文（LessonPlanLM、北极星、SciEval、GenAI Lesson Planning）。

---

## 一、四个权威体系如何定义维度

### 1. EQuIP Rubric for Science（教学材料评测的国际事实标准）

三大类 19 条准则（Category I 6 条 / II 7 条 / III 6 条），每条四级评分（None / Inadequate / Adequate / Extensive）：

| 类别 | 准则 | 对应我们的维度 |
|---|---|---|
| **I. NGSS 3D Design（对齐类）** | I.A 解释现象/设计方案驱动学习；I.B 三维整合；I.C 三维融合；I.D 单元连贯；I.E 多学科域；I.F 数学与 ELA 融合 | 1（目标对齐）、4（环节连贯） |
| **II. Instructional Supports（教学支持类）** | II.A 真实相关性；II.B 学生想法；II.C 学习进阶；**II.D 科学准确性**；II.E 差异化教学；II.F 教师支持；II.G 随时间支架式差异化 | 2（准确性）、3（学段进阶）、7（差异化/学情）、9（学生想法） |
| **III. Monitoring Student Progress（评价类）** | III.A 监测三维表现；III.B 形成性评价；III.C 评分指引；III.D **无偏任务**；III.E 连贯评价系统；III.F 学习机会公平 | 8（教—学—评一致）、6（无偏/公平） |

**关键机制**：Category I 是**门槛**——"若第一类准则不满足，无需继续评测"（gate 机制，与我们 G0 准入同构）。II.D 科学准确性是独立准则。

### 2. Danielson Framework for Teaching 2022（教师评价全球标杆）

4 领域 22 组件 76 要素。与**教学设计文本**最相关的是 Domain 1（计划与准备）6 组件：

| 组件 | 内容 | 对应我们的维度 |
|---|---|---|
| 1a 内容与教学法知识 | 学科专长、PCK、前置关系 | 2 |
| 1b 了解学生 | 当前知识技能、发展差异、学生身份 | 7 |
| 1c 设定教学成果 | 与年级标准对齐、目的清晰 | 1、3 |
| 1d 资源使用 | 教学材料、技术资源、学生支持 | —（超出范围） |
| 1e 设计连贯教学 | 任务活动、结构流程、弹性学习 | 4 |
| 1f 设计与分析评价 | 与成果一致、形成性评价计划 | 8 |

Domain 3（学习体验）中 3b 提问与讨论技术（批判性思维、推理、学生参与）、3e 灵活回应学生需求，对应维度 9。

### 3. 教育部"一师一优课、一课一名师"官方量表（国内权威口径）

**上海市级"优课"评价量表（教学设计模块 40 分）**，四个二级指标：
- **目标设计**：符合课标的程度（准确性）、切合学生的程度（适切性）
- **内容设计**：严谨正确（科学性）、联系实际（应用性）、突出重点（要点性）
- **过程设计**：整体性、方法手段关联目标（关联性）、针对实际（针对性）、**评价设计促进学习（促进性）**
- **作业设计**：基于目标（解释性）、分层分类（多样性）

**杨陵/汉源推优参考标准（教学设计部分）**：三维目标明确具体可行、体现学段认知特点；围绕目标和学情精选内容、重难点清晰；步骤清晰结构完整；板书简明；**作业设计体现差异性**。

**共同口径**：教学设计模块必查 = 目标（对课标+对学生）→ 内容（正确+重难点）→ 过程（含评价）→ 作业（分层）。注意官方量表把"科学性/正确性"拆在内容设计和实施里，未单列一票否决——这是我们的改进点而非缺口。

### 4. LLM 教学设计评测论文（学术前沿口径）

| 工作 | 维度 | 备注 |
|---|---|---|
| **LessonPlanLM**（Nature 子刊） | 总维度 4 个：结构健全性 / 内容准确性 / 逻辑一致性 / 语言精细度；**组件级 8 项**：结构、内容准确性、SLA 学情分析、LO 教学目标、KDP 重难点、MAT 教具材料、LP 教学过程、AM 作业与评价（每项 1–3 分带评分细则） | 组件级拆分与我们 8+1 粒度最接近 |
| **北极星**（北师大） | 教案生成 5 维：结构完整性 / 内容准确性 / 内容一致性 / 语言逻辑性 / 素养导向性 | 实证发现内容准确性是唯一高区分度维度 |
| **SciEval**（AIED） | EQuIP 13 条改编，任务=分数+页码级证据引用 | 证据引用机制与我们"证据清单+原文引用"一致 |
| **GenAI Lesson Planning** | 7 个 Likert 维度：相关性 / 准确性 / 创造性 / 参与度 / 个性化 / 连贯性 / 响应时间 | 轻量口径，参考价值较低 |

|---|---|---|---|---|---|

## 三、结论：权威性评估

**① 每个维度都有 ≥2 个权威体系独立锚定，8/10 个维度是"四源/三源齐锚"**。维度体系不是自创的，是权威口径的收敛点。特别是：
- **G0 知识准入**：与 EQuIP Category I 门槛机制同构，且被北极星实证（准确性=唯一区分维度）、SciEval 实证（LLM 裸判抓不住准确性）双重验证；
- **教—学—评一致性（20%）**：名称直接采用义务教育课标 2022 的官方口径（"注重实现'教—学—评'一致性"原文），国内外四源一致；
- **权重倾斜合理**：目标 20 + 一致性 20 = 40% 压在官方量表同样最重的"目标设计+评价设计"上；表述 5% 低权重与北极星"语言维度趋近满分无区分度"实证吻合。

**② 无结构性缺口（在边界内）**。权威体系中有而我们没有的维度只有三个，均为**有意识的范围排除**且与方案边界一致：
- 信息技术应用（国内官方量表单列）——我们评 AI 生成的教学设计文本，不评课堂实施与技术使用，Out of Scope 已声明；
- 跨学科连接（EQuIP I.F、部分评课表）——单课时数学教学设计范围内非核心；
- 家校/专业职责（Danielson Domain 4）——属于教师行为而非设计文本，评测对象不可见。

**③ 我们有两处超出权威基准的加强设计**（可作为方案亮点）：
1. **确定性准入一票否决**：国内官方量表和 LessonPlanLM 都把正确性当普通维度计分，我们用规则层+知识库断言做成 G0 门槛——直接回应北极星"准确性既是瓶颈又最难判"的痛点；
2. **防伪质量对抗**：权威评规没有专门条款对付"堆砌术语骗过浅层检查"，我们的维度 1 强制规则（声称符合课标不给内容不加分）+ 对抗性实验是增量贡献。
