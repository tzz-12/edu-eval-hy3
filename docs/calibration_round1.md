## 3. 三个关键发现

### 3.1 断言集课题覆盖是硬缺口（3/4 样本被拒评）

Tier2 断言集覆盖 13 课题（一元一次方程/二次函数/全等三角形等），**不含平行四边形、
正方形、平面镶嵌** → G0 准入 NE 诚实拒评（机制正确，但覆盖面限制了校准样本量）。
补救路径：a) Hy3 为校准课题补 Tier2 断言（走 P1-1 同款流程）；b) 校准期放宽准入。

### 3.2 真实专家课 = 76 分（良好）——这是分层阈值的最重要锚点

- 一份经专家团队审核、信息化融合的示范课只拿 76 分，维度 1/5/6/7/8/A 全部 3 分
- 若 A 线定 90+，**真实优秀教案几乎不可能达 A** → 提案中的 L3 条件（L2 四维中 3 个
  满分）本样本恰好差一个（2/4/9 满分，但 8/7 是 3 分）——A 线有区分度但可能过严
- L1 封顶条件（任一维度≤2 分）本样本未触发 → 真实优秀课不会误入 C-，机制健康

### 3.3 Judge 打分疑似"中间塌缩"（3/5 两极，n=1 待验证）

全维度样本 9 个有分维度中 5 个 3 分、4 个 5 分，没有 2 分和 4 分。样本量不足以下结论，
但若后续样本仍如此，说明锚点描述需要引导 Judge 使用 2/4 档。

## 4. 对四个分层决策点的启示

| 决策点 | 校准数据启示 |
|---|---|
| R3 逻辑红线 | 4 份真实课均无逻辑断裂 → 维持"严重断裂=不可实施"口径不会误伤 |
| L1 封顶 70 分 | 真实优秀课不触发 L1 → 封顶机制不影响好样本，可保留 |
| L3 优秀条件 | 专家课 76 分 → A 线 90+ 会让真实样本达不了 A；建议 A 线下调至 85 左右，或 L3 条件改为"L2 四维中 ≥3 个 ≥4 分且至少 2 个满分"（待更多样本） |
| 等级+百分制并行 | 二次函数样本 76 分/"良好"同时给出，阅读与统计两用 → 验证可行 |
