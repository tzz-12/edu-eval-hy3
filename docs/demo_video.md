## 1. 录制前准备（约 3 分钟）

```bash
cd /Users/tzz/WorkBuddy/edu-eval-hy3

# ① 确认 .env 的裁判配置（HY3_BASE_URL / HY3_API_KEY / HY3_MODEL）。
#    当前生效的模型名会出现在报告卡的「裁判」徽标上，录屏时这本身就是口径证据。

# ② 预生成 3 份演示报告——录屏时秒开，不用现场等。
#    注意：当前裁判单次调用约 200s，单份报告约 30~40 分钟，请提前起跑。

# ③ 起服务（live 模式）
bash scripts/run_demo.sh start 8000 --live
```

画面准备：

- 浏览器窗口 **1280 × 800**，缩放 100%
- 收起书签栏（`⌘⇧B`），关掉其它标签页与通知，避免泄露个人信息
- 若是首次运行，侧栏历史为空——**这是预期行为**（演示样本不入历史库），不用先造数据

## 2. 分镜表（合计约 110 秒）

| # | 时间 | 时长 | 画面与操作 | 字幕（必加，允许不配音） |
|---|---|---|---|---|
| 1 | 0:00–0:12 | 12s | 停在欢迎页，鼠标轻划过长标题与能力三栏 | EduEval —— 基于混元 Hy3 的初中数学教学设计质量评估器 |
| 2 | 0:12–0:22 | 10s | 点右上角 **?** 打开「评测说明」，停在维度清单 | 评测标准公开：10 个维度、权重、1·3·5 分锚点 |
| 3 | 0:22–1:00 | 38s | 点演示样本 **① 好样本 · 二次函数** → 报告总览（判定 + 总分 + 雷达图 + 维度速览）→ 切到「维度详情」滑一屏 → 切到「一致性」 | 好样本：准入通过、总分 95 优秀；双采样的两个视角一致，分数直接取平均 |
| 4 | 1:00–1:18 | 18s | 回欢迎页 → 点 **② 硬伤 · 公式错误** → 报告在 1 秒内返回 FAIL | 知识错误由规则层拦截：零 LLM 调用、约 0.5 秒出结果，不进入评分 |
| 5 | 1:18–1:36 | 18s | 回欢迎页 → 点 **③ 软伤 · 伪启发** → 总览红线通知 → 「维度详情」滚到维度 6/9 | 伪启发包装：表面有提问、实际自问自答 —— 被判严重违背育人目标，触发安全红线不通过，维度 6/9 均低分 |
| 6 | 1:36–1:50 | 14s | 停在报告总览，或切回欢迎页 | 确定性规则层负责可验证项，语义判定全部由混元模型 API 完成 |

若时间不够，删掉第 5 镜（保留 ①② 即达标）。

## 3. 录制

macOS 自带录屏即可：

```
⌘⇧5 → 选择「录制所选部分」→ 框住浏览器窗口 → 录制
录完在右上角停止，桌面会出现 .mov
```

要点：

- **不要录整屏**，只框浏览器窗口，后期省去裁切
- 真实评测一份约 2~25 分钟，**别直播等**：直接用预生成的演示样本（1 秒出报告）
- 第 3 镜滑「维度详情」时速度放慢，让评委看清维度名与分值

## 4. 后期与导出

```bash
# ① 裁成 ≤ 110 秒、压缩体积（H.264 / 1280 宽）
ffmpeg -i raw.mov -t 110 -vf "fps=30,scale=1280:-1:flags=lanczos" \
       -c:v libx264 -crf 24 -preset slow -pix_fmt yuv420p -an docs/demo.mp4

# ②（可选）再出一份 GIF，宽 960 / 12fps，控制在 10MB 内
ffmpeg -i docs/demo.mp4 -vf "fps=12,scale=960:-1:flags=lanczos,split[s0][s1];[s0]palettegen[p];[s1][p]paletteuse" \
       docs/demo.gif
```

- MP4 优先（体积小、画质好）；GIF 只在需要插进 PPT / 在线文档时再出
- 字幕用剪辑软件烧进去，或用 `ffmpeg -vf subtitles=sub.srt` 挂载
- 成品放 `docs/demo.mp4`，随后**在 README 里补链接**（见下）

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 点演示样本按钮 404 | `data/demo_reports/` 为空，先跑 `bash scripts/run_demo.sh pregen --live` |
| 评测转圈很久 | 走的是实时评测（30~90 秒正常）；录屏请用演示样本，别用实时评测 |
| 报告里的模型与 `.env` 不一致 | 报告是旧条目，重跑 `pregen_demo_reports.py` 对应样本即可 |
| 录出来文件过大 | 降 `-crf` 到 26~28，或把 fps 降到 24 |
