# 权威评测体系建设方法调研

> 调研目的：为 EduEval 评测器的建设方法论寻找权威参照。
> 调研时间：2026-09-02。资料来源：各基准原始论文 / 官方复盘文章 / 教育垂直领域最新工作。

---

## 一、通用基准是怎么"从零建起来"的

### 1. MMLU（2020，Hendrycks et al.）——"收集汇编"路线

- **选题定位**：57 个学科、四选一选择题，测"模型已具备的知识"，不提供任务训练集
- **建法**：研究生人工从网上免费公开材料收集（GRE / USMLE 练习题、大学课程题、教材习题）
- **质量基线**：测了人类基线——非专家众包 34.5%，专家估计 89.8%，随机猜 25%
- **数据划分**：dev 285（few-shot 示例）/ val 1,540（调参）/ test 14,079（报告分数）
- **事后教训**：MMLU-Redux 专家复查 5,700 题发现 **6.49% 题目有错**；且存在训练集污染嫌疑。
  → 说明"收集现成题"路线的固有缺陷，后来者纷纷改用手工制题

### 2. GSM8K（2021，OpenAI）——"众包自写 + 交叉复解"路线

- **建法**：Upwork 自由撰稿人先写 1,000 题 → Surge AI 平台扩规模；允许参考 GPT-3 生成的种子题，但强制要求变换情境、避免模板化
- **核心质控：交叉复解**
  - 另一批标注者**独立重解所有题**（原写题人不解自己的题）
  - 答案不一致的题：修复或丢弃
  - 二轮抽查：残余分歧率 1.7% → 估计全集 <2% 破坏性错误
- **诚实报告**：明确声明"可能存在更多不易察觉的隐性错误"（一致性估计 ≠ 全对证明）

### 3. C-Eval（2023，上交/清华/爱丁堡）——"手工制题 + 防污染"路线（官方复盘文章最有参考价值）

- **第一决策：从头手工制作，不用网上现成网页题**——网页文本大概率已被爬进预训练集
- 题源用 **PDF/Word**（OCR 电子化 → Markdown 统一格式 → 数理内容统一 LaTeX）
- **公式全部人工逐条验证**：十来位同学花近两周，13,000+ 题里所有符号内容（公式、化学式）逐一核对——"能自动转 LaTeX 就自动转，不能就手敲"
- **CoT 示例自己做**：GPT-4 生成的 CoT 错误率太高，改为同学基于 GPT-4 草稿亲手重解每个学科 5 道示例
- **防污染三招**：
  1. 测试集**只公开题目不公开答案**，本地跑完提交计分
  2. **全部用模拟题，不用任何真题**（真题广泛存在于网上）
  3. 官方明确"防爬虫混入训练集"为设计目标
- **迭代方式**：邀请字节/商汤/深言等接入工作流测试，从开发者反馈持续迭代（黑盒测试、小模型定答案方案等需求都来自反馈）
- **立场**："最重要目标是辅助模型开发，而不是打榜"

### 4. CMMLU（2023）——中规模人工标注的质控样本

- 4 名本科以上标注者，250 小时；**>80% 数据爬自 PDF（OCR 后）**以降低混入训练集概率
- 刻意选取非公开材料、模拟题、综艺题
- **质检**：每学科随机抽 5% 带答案题目人工在线核验 → 估计约 2% 噪声（答案缺失或标错）
- 判断："多数模型平均准确率不到 60%，2% 噪声不影响总体结论"——**误差率与被测能力差距足够大时，可接受的质量水平**

### 5. MT-Bench / Chatbot Arena（2023，Zheng et al.）——LLM-as-Judge 的"合法性证明"与校验方法

- **核心实验**：GPT-4 作 Judge 与人类专家一致性 **85%**（S2 口径），高于人类之间的一致性 81% → LLM 判官获得了方法论上的"入场券"
- **三种判分模式**：
  | 模式 | 适用 | 特点 |
  |---|---|---|
  | Pairwise 两两比较 | 排名、A/B 测试 | 最可靠，但无绝对分下限 |
  | Single-answer 按 rubric 打分 | 生产评测 | 可扩展、可设通过阈值 |
  | Reference-based 参照标准答案 | 数学/事实类 | **硬题必备** |
- **关键发现（对 EduEval 直接有用）**：
  - 数学/推理题 LLM 直接判失败率 70% → **reference-guided（先给标准答案再判）降到 15%**
  - 已知偏差：位置偏差、长度偏差、自我增强偏差（自 family 判自己偏高）
  - 校验协议：100–500 条金标集、人类专家同 rubric 打分、算 Cohen's κ（>0.6 中等、>0.8 生产级）
  - rubric 会"漂移"（criteria drift），写好的 rubric 不应视为终稿

## 二、教育垂直领域：与 EduEval 最相关的三个工作

### 1. 北师大"北极星"基础教育大模型评测场（三期，2025–2026）——最直接的同行

- **教案生成评测五维度**：结构完整性 / **内容准确性** / 内容一致性 / 语言逻辑性 / 素养导向性
- **核心发现（与 EduEval 的 G0 设计撞了个正着）**：
  - **内容准确性是当前教案生成模型的主要瓶颈**——五个维度中得分最低、模型间差距最大
  - 结构完整性/一致性/语言逻辑性普遍接近满分（区分度低）
  - → 印证 EduEval 把"知识绝对正确性"设为 G0 准入门槛的判断是对的：
    **该维度既是真瓶颈又是最大区分器**
- 三期纵向追踪（同题重测），观察模型能力随时间演进

### 2. SciEval（2026，Buffalo/WSU，K-12 科学教学材料自动评测）——与 EduEval 任务形态最接近

- 提出 **AIME 任务**（Automatic Instructional Materials Evaluation）：预测分数 + 证据
- **rubric 由教育者设计**：采用 EQuIP 评规（美国 K-12 教材评审权威标准，三大类 13 条准则）
- **数据集**：273 份课时级教学材料，专家标注，**高评分者间信度**（inter-rater reliability），共 3,549 条评分
- **发现**：主流 LLM（GPT/Gemini/Llama/Qwen）直接评**没有一个表现强**；领域对齐微调可提升 11%
- 启示：教学材料评测对 LLM 是**困难任务**，纯 prompt 的 judge 不可信，必须有高质量人工标注参照

### 3. LessonPlanLM（2025，Nature 子刊，教案生成+评测）

- **人工标注流程（可借鉴的质控模板）**：
  - 3 名标注者，先做多轮**培训试评**（每人独立评 20 份教案 × 多轮）
  - 一致性定义：两两总分差 <5 分记一致 → **Fleiss Kappa = 0.83**（>0.6，良好）
  - 达到高一致性后才协作标注正式测试集（200 份教案 / 1,400 组件）
  - 评测阶段每模型随机抽 50 份三人独立评，持续监控一致性
- **重要教训**：尝试 GPT-4 自动打分，**与人工评分差距过大，判定 GPT-4 不能胜任标注**，最终全人工
- 教案评测维度含：内容准确性、逻辑一致性、语言精细度、材料使用、冗余性、主观语言等细粒度评分项

### 4. 其他参照

- **EdTech Hub（伊斯兰堡公立学校 AI 教案评估）**：8 条准则——课标对齐、教学设计连贯、内容清晰准确、差异化适配、学生参与、教师易用、评价整合、无障碍包容性
- **EduPlanner CIDDP**：教学设计五维 LLM 评测（Clarity/Integrity/Depth/Practicality/Pertinence），评测 Agent 用 100 份专家标注教案训练后"评测能力可比人类专家"

## 三、权威评测体系建设的共性规律

按"从零建立"的顺序归纳，各家做法高度收敛于以下步骤：

| 步骤 | 权威做法 | EduEval 现状 | 差距/行动 |
|---|---|---|---|
| 1. 定义测什么（构念） | 先论证"什么能力区分强弱"再出题（C-Eval 花大量篇幅论证知识+推理） | ✅ 8 维 + G0，且维度设计有教育理论支撑 | 已达标 |
| 2. 决定题目来源 | 自写/手工收集，**刻意避开公开网页真题防污染**（C-Eval/CMMLU/GSM8K 一致） | ✅ Hy3 自然生成 + 程序化注入，天然无污染 | 已达标 |
| 3. 真值（ground truth）建立 | **交叉复解 / 多人独立标注**，不一致即修或弃（GSM8K 交叉复解、LessonPlanLM 三人标注） | ⚠️ 注入器真值是程序化的（对注入样本够用）；自然样本**没有人工金标** | **补人工金标**：教师本人对子集独立评分 |
| 4. 一致性量化 | Kappa / 分歧率，阈值 κ>0.6（LessonPlanLM 0.83、CMMLU 2% 噪声） | ⚠️ 计划中的"一致性实验"未定义指标口径 | 明确用 Kappa 或 pairwise 一致率 |
| 5. Judge 可信度论证 | LLM-as-Judge 必须对人类金标校准（MT-Bench 85%）；**数学/事实类必须 reference-guided** | ✅ 已走 reference 路线（Tier2 断言=参照答案）；三实验设计对应此环节 | 实验时补判官-人类一致率数字 |
| 6. rubric 锚点 | 强制规则 + 反套路条款（不按提问数量评分等）；rubric 会漂移需迭代 | ✅ 每维 1/3/5 锚点 + 强制规则已写死 | 保留"rubric 可迭代"的余地 |
| 7. 诚实报告边界 | NE/不确定如实输出（MMLU 事后 6.49% 错误教训、GSM8K <2% 声明） | ✅ NE 语义、"缺失结论≠判错"已内化 | 在报告与论文中显式声明 |
| 8. 纵向可复用 | 同题重测追踪演进（北极星三期） | ⚠️ 一次性实验设计 | 开发集固定 seed、可重复跑 |

## 四、对 EduEval 最关键的 4 条结论

1. **路线被验证**：EduEval 的"知识准确性设为 G0 准入 + 教学质量加权评分"与北极星评测场的发现完全一致——内容准确性是教育大模型输出**唯一拉开差距的维度**，其余维度趋近饱和。
2. **必须补人类金标**：所有权威评测的合法性都来自"对人类标注校准"。注入样本有程序化真值，但自然生成样本（好/中/差）需要教师本人作为领域专家对子集打分，算 Judge-人类一致率——这是三实验中"一致性实验"的正确姿势。
3. **reference-guided 路线选对了**：MT-Bench 证明数学/事实类 LLM 直接判失败率 70%，给参照后降到 15%——Tier2 断言集充当参照答案的设计正是权威推荐做法。
4. **防污染自觉性可写进卖点**：C-Eval/CMMLU 花大力气避开网络真题；EduEval 样本由 Hy3 按课题参数生成 + 种子固定，天然规避了训练集污染，这一点在方案与论文中值得显式强调。
