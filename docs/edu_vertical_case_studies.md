## 一、北师大"北极星"基础教育大模型评测场

### 1.1 是谁、怎么运作

- **共建方**：北师大智能技术与教育应用教育部工程研究中心 + 教育人工智能北京市重点实验室 + 北京教育科学研究院 + 北京智源人工智能研究院；市教委指导、市科委支持、北京市数字教育中心资助
- **定位**：**首个基础教育领域的大模型评测场**（www.bnueval.com）
- **运作方式**：官方榜单制，**定期重测**（三期：2025-06 / 2025-10 / 2026-06），同一批任务维度纵向追踪模型演进——不是一次性论文基准，而是持续运营的评测机构

### 1.2 评什么（6 大场景）

智能解题、智能答疑、智能出题、教案生成、口语练习、作文批改。
覆盖初中学段为主（解题 8 大学科，出题/教案为初中数学、物理、化学）。

### 1.3 教案生成评测（与 EduEval 直接对标）

- **五维度**：结构完整性 / **内容准确性** / 内容一致性 / 语言逻辑性 / 素养导向性
- **关键发现**：
  1. 结构完整性、内容一致性、语言逻辑性**普遍接近满分**——没区分度
  2. **内容准确性五维最低、模型间差距最大**，头部与中尾部模型明显分层
  3. 学科差异化短板：数学整体最高但素养导向性不足；**物理化学短板集中在内容准确性**；实验类课程"重难点分析、实验原理和现象解释"普遍缺失或展开不足
- **三期趋势**：整体稳步提升，教案生成"从能生成完整教案的基础阶段迈向更高质量阶段"——但内容准确性始终是瓶颈

### 1.4 其他场景的可借鉴发现

| 场景 | 发现 | 对 EduEval 的含义 |
|---|---|---|
| 智能解题 | 客观题均分 92.4 vs 主观题 81.7，分差与模型综合能力负相关；**记忆识别型维度趋同（σ=6.7），操作表达/推理计算型才是区分器（σ=10.4/11.4）** | 评测维度要选"能拉开差距的"，饱和维度没有信息量 |
| 智能答疑 | 6 维（语言流畅/合理反馈/导正话题/分步骤讲解/提问质量/引导质量）；引导质量提升最大（53.29→80.18）但仍是低分维度 | "启发引导"类维度难且有价值——与我们维度 9 呼应 |
| 智能出题 | 9 类复杂命题约束；复杂需求使素养导向性 +12 但**解析准确性/知识点匹配度下降** | 约束越复杂，准确性越掉——支持我们"知识正确性需硬核验"的立场 |
| 作文批改 | **"低分高估、高分低估"的分段性偏差**：LLM 因偏好对齐倾向鼓励性反馈，不愿给低分；高阶质量特征识别不足 | **LLM 判官的系统性偏差的直接证据**——我们的对抗实验（伪启发包装）正是要抓这种"表面合规" |

### 1.5 对 EduEval 的启示

1. **G0 设计被独立验证**：内容准确性 = 唯一瓶颈 + 唯一区分器，恰好是我们设为准入门槛的维度
2. **维度设计要保留区分度意识**：结构/格式类维度会快速饱和（北极星实证），我们维度 A 设为辅助不计总分是对的
3. **榜单制运营模式**：固定题集 + 定期重测 + 三期对比，是"评测场"区别于"一次性论文"的关键；EduEval 论文可展示"同一开发集可重复评测"
4. **学科差异化结论**可引用：理化内容准确性短板、实验类课程重难点缺失——与我们覆盖数学并预留物理扩展的规划一致

## 二、SciEval：K-12 科学教学材料自动评测（AIED 2026）

### 2.1 任务定义（AIME）

- **AIME（Automatic Instructional Materials Evaluation）**：输入 = 评规准则 + 完整教学材料 PDF 文本（带页码标记）；输出 = JSON（准则 id、0–3 分、**证据**：1–2 句总结 + 1–3 条逐字引用并附页码）
- **关键立场**：把教学材料评估从"分类打分"重构为"**生成带证据的反馈**"——可解释、可核验，这对教师用户才有用

### 2.2 评规：不是自造，采用教育界权威标准

- **EQuIP Rubric v3.0**（Achieve, Inc. 发布，配合 NGSS 下一代科学标准），13 条准则，三大类：三维学习对齐（DCI/SEP/CCC）/ 教学支持 / 评估机会
- 评分 0–3：0 = N/A（无对应证据）、1 = Inadequate、3 = Extensive

### 2.3 数据集构建（最值得学的是三轮标注流程）

- **来源**：4 家获 NGSS Quality Badge 认证的开放机构（OpenSciEd、BSCS、CREATE for STEM、K-12 Alliance at WestEd），32 个教学单元 → **273 份课级材料**（平均 16.5 页 / 5,908 词），共 **3,549 条准则级标注**
- **单元级→课级迁移**：EQuIP 原为单元级评审，开发系统化流程从官方 EQuIP 报告提取准则级分数，并定位课级证据；无法追溯的记 missing——**不编造**
- **三轮标注（人员：2 名编码员 + 2 名资深研究者主导培训/裁决）**：
  | 轮次 | 内容 | 信度 |
  |---|---|---|
  | Round 1 | 2 单元 29 课独立标注 | **κ = 0.227**（差！） |
  | — | 2 次结构化裁决会议，建立共享决策规则 | |
  | Round 2 | 同 29 课重新独立标注 | κ = 0.724，ICC = 0.725，一致率 89.7% |
  | Round 3 | 23 单元 221 课全量，24 课持续双编码监测 | **κ = 0.858，ICC = 0.872，一致率 95%** |
- **教训**：首轮 κ=0.227 说明教育评规的主观判定**初始一致性天然很低**，必须靠裁决会议 + 共享决策规则拉上来——信度是"训练出来的"，不是天然存在的
- **标签长尾**：0 分（N/A）占 41.8%——刻意保留，用于测试模型**该"弃权"时能否弃权**（与我们 NE 语义同构）
- **切分**：按文档级 218/55 划分 + 分层抽样，防内容泄漏

### 2.4 LLM 基线结果（泼冷水实验）

- 测 GPT-4o-mini、Gemini-2.0-Flash、Llama-3.1-8B/3.2-3B、Qwen3-4B-Instruct/Think，3 种提示词（含领域术语 few-shot / 同结构 zero-shot / 简化版）
- **结果：没有任何模型表现强**。最佳基线 QWK（二次加权 Kappa）仅 16.23，最佳微调也仅 25.73——对比人类 κ=0.858，差距巨大
- 有趣细节：
  - **简化提示词 C 最优**（降低复杂度让模型聚焦，缓解过拟合）
  - **商业模型无法预测 0 和 1 标签**（低分标签盲区）
  - Qwen3-4B-**Thinking** 表面 Acc 最高（53.85）但 QWK/EMR 双 0——坍缩为多数类预测（**推理型模型评教材料反而坍缩**，与我们 hy3 推理预算问题的经验呼应）
  - Instruct 版优于 Thinking 版

### 2.5 微调实验

- LoRA SFT（r=16，6 epochs，H100 约 10h）+ 数据增强（下采样 0 类、翻译增强过采样少数类）
- 提升：Recall +11%、F1 +9.2%、QWK 16.23→25.73——**有帮助但远未解决**
- **证据定位未随微调提升**（EMR 基线 36.04 → 微调后 11.42/28.42）

### 2.6 失败模式（对我们最有价值的部分）

1. **页码级定位错误**：案例中模型分数判对、SEP 识别对、语义相关文本也对，**但证据所在页码错**（真值在 Teacher Edition p.88）——"语义正确但页码错误会阻碍教师核验"，EMR 这种语义相似度指标测不出这个问题
2. **长文本证据提取普遍困难**（Lost-in-the-Middle）
3. 商业模型低分标签盲区

### 2.7 对 EduEval 的启示

1. **"分数 + 证据引用"的输出形态是权威方向**——我们 Judge 要求 KB#证据引用与此一致，且可将"Evidence Match"（证据是否真的来自所引材料）作为未来指标
2. **信度是训练出来的**：首轮 κ=0.227 → 裁决 → 0.858 的路径，正是我们"教师金标子集"该走的流程：先试评对齐 → 裁决规则 → 正式标注 → 持续监测
3. **0/NE 占比要刻意保留**：能测"弃权能力"；商业模型的低分盲区提示我们要在锚点里强制低分判定
4. **纯 prompt 的 LLM 评教学材料不可信**（QWK 最高 16~26 vs 人类 0.86）——为我们的"规则层 + 知识库参照 + 人工金标校准"组合拳提供了最直接的立论依据

## 三、LessonPlanLM：知识增强的教案生成与人工评测（Nature HSSC 2025）

### 3.1 定位

本质是**教案生成**论文（LPKB 知识库：10 万+ 真实教案，课程抽取器 + 语义收集器 + 知识检索器；SFT + RAFT 检索增强微调），但它的**评测体系**是教案质量评测最完整的人工标注范例。

### 3.2 评测维度（四维，1–3 分）

| 维度 | 考察 |
|---|---|
| Structure Soundness 结构合理性 | 层级清晰、布局合理 |
| Content Accuracy 内容准确性 | 每个组件与课程信息对齐（细到 7 个子组件：TA/SLA/LO/KDP/MAT/LP/AE——教学分析、教学目标、重难点、教学过程、材料、板书、作业评价） |
| Logic Consistency 逻辑一致性 | 同一教案内各组件间一致 |
| Language Finesse 语言精细度 | 清晰、连贯、流畅 |
| Overall | 四维平均 |

评分项设计极细：例如"材料未全面覆盖教学过程实际用到的材料""单个模块目标与其他模块核心目标不一致""出现 1–2 处'我认为/老师可以'类主观语言"都有对应扣分档位——**rubric 粒度到了"可机械对号"的程度**。

### 3.3 人工标注流程（黄金模板）

1. **人员**：3 名专家教师（≥5 年教龄）评分 + **2 名认证数学教师（≥10 年）专职仲裁分差大的样本**——"评分者 + 仲裁者"双层结构
2. **培训试评**：多轮，每轮每人独立评 20 份教案 → 每份 3 个独立分数
3. **一致性定义**：两两总分差 <5 分记 1，否则 0 → 算 **Fleiss Kappa = 0.83**（>0.6 阈值，良好）
4. **正式标注**：达到高一致后才**协作标注**正式测试集（200 份教案 / 1,400 组件）
5. **持续监测**：评测期每模型随机抽 50 份教案 / 350 组件由三人独立评，算 Kappa 确认评测全程一致性未滑坡

### 3.4 GPT-4 自动打分尝试——失败的实证（最有引用价值）

专门构造了逐维提示词让 GPT-4 打分，与人类评分对比（Table 7）：

| 方法 | 人类 Overall | GPT-4 Overall | 偏差方向 |
|---|---:|---:|---|
| iFlytek Spark 3.5 的教案 | 1.977 | 1.716 | -0.26 |
| GLM-4 的教案 | 1.672 | 2.069 | **+0.40** |
| LessonPlanLM-7B 的教案 | 2.709 | 2.082 | **-0.63** |
| LessonPlanLM-72B 的教案 | 2.843 | 2.169 | **-0.67** |

差距过大且**方向不稳定**（有的高估有的低估），作者结论："GPT-4 不能完成教案标注"，**最终全人工评测**。

- 附带发现：即使强如 GPT-4 生成的教案，人工评的内容准确性（2.295–2.370）也明显低于结构合理性（2.995）——**内容准确性瓶颈第三次被独立验证**

### 3.5 对 EduEval 的启示

1. **"评分者 + 仲裁者"双层人工结构**可直接复制：你做主评（数学专家），分差大的样本引入第二位数学教师仲裁
2. **先试评对齐再正式标注**：试评 → Kappa 达标 → 协作标注 → 评测期持续抽检，这套四步流程就是论文里"人类金标"部分的方法学章节骨架
3. **细粒度评分项**（"1–2 处主观语言扣分"级别）值得借鉴——我们维度锚点可再下沉一层到可机械对号的评分项
4. **GPT-4 失败实证**是我们论文中"为什么不能只靠 LLM Judge"的最强外部证据——注意它评测的是"教案质量"这种复合判断，而我们用"参照答案 + 规则层"改造后 LLM Judge 是可行的，这个**对比本身**（MT-Bench reference-guided 70%→15% vs LessonPlanLM 裸判失败）正好构成我们方法设计的完整论证链

## 四、三个工作横向对比

| 维度 | 北极星 | SciEval | LessonPlanLM |
|---|---|---|---|
| 性质 | 持续运营的官方评测场（榜单制） | 学术基准 + 数据集发布 | 生成系统的评测体系 |
| 评什么 | 6 场景（解题/答疑/出题/教案/口语/作文） | 教学材料按 13 条 EQuIP 准则 | 生成教案按 4 维 |
| 题材来源 | 自建评测集（紧扣新课标） | 4 家认证开放机构教材 | 系统生成 + 人工评 |
| 真值 | 官方组织专家评测 | 2+2 人三轮标注，κ 0.227→0.858 | 3 评分 + 2 仲裁，Kappa 0.83 |
| 判分方式 | 专家评测（官方口径） | LLM 基线对比人类金标 | 全人工（GPT-4 判分被证伪） |
| 核心发现 | 内容准确性 = 唯一瓶颈与区分器 | LLM 直接评教学材料远未达人类水平 | GPT-4 无法胜任教案标注 |
| 规模 | 6 场景多模型多期 | 273 课 / 3,549 标注 | 200 教案 / 1,400 组件 |
| 对 EduEval 最大价值 | 维度设计验证 + 榜单制范式 | 标注信度训练流程 + 失败模式 | 人工标注 SOP + GPT-4 失败实证 |

## 五、共同结论（三条铁律）

1. **内容准确性是教育内容评测中唯一既难又高区分度的维度**——三个工作独立验证，EduEval 的 G0 设计站在了正确位置
2. **LLM 裸判教学材料不可信**（SciEval QWK≤26 vs 人类 0.86；LessonPlanLM 中 GPT-4 偏差高达 0.67 且方向不稳）——必须有参照（reference）或规则层兜底，EduEval 的 Tier2 断言 + 规则层 + 人工金标三层架构正是对症下药
3. **人类信度是流程产物**：试评 → 裁决规则 → 达标 → 正式标注 → 持续监测，κ 从 0.23 训练到 0.86——EduEval 的人工金标子集必须走同样流程，且这个流程本身就能写进论文方法学
