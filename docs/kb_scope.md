# 知识库范围声明（13 课题闭环）

> 本文是 EduEval 知识库的**范围边界文件**：Tier 1 覆盖全部初中概念，
> Tier 2 只覆盖 13 个核心课题的可核验断言。范围外断言按设计返回 `NE`
> （Not Evaluable），属**可声明的边界**而非缺陷。

## 1. 范围决策的依据

- **评测集课题范围**：人教版初中数学 13 个核心课题（见下表）。
- **验收指标**：评测集核心知识覆盖率 ≥ 90%（DESIGN.md §5）。
  「核心知识」指 13 课题的核心概念与断言，非全部 451 个初中概念。
- **可行性**：Tier 2 全量覆盖 451 概念在工期与校验成本上不可行；
  13 课题 × 8–15 条断言 = 130–180 条，是「高价值、低体量」的最优取舍。

## 3. Tier 1 / Tier 2 边界

| | Tier 1 概念索引 | Tier 2 可核验断言 |
|---|---|---|
| 覆盖 | 初中全部 451 Concept（100%） | 13 课题核心断言（126–165 条） |

## 4. 范围外行为（声明）

1. **非初中概念**（如高中「导数」「复数」）出现在教学设计中：
   维度 3 直接判严重超纲（Tier 1 图谱含高中节点，可区分）。
2. **初中概念但非 13 课题**（如「轴对称」「概率初步」）：
   - Tier 1 检索与超纲判断**正常工作**（451 概念全覆盖）；
   - G0 断言核验返回 `NE`，报告标注「断言集未覆盖该课题」。
3. **越界年级**（如九年级概念出现在七年级设计中）：
   维度 3 确定性查表判超纲，给出概念名与所属册次作为硬证据。

## 5. 已知局限（实测，非推测）

构建完成后对 13 课题的 40 个核心概念做了覆盖审计，结果见
`data/testsets/kb_gaps.json`（`scripts/build_retrieval_testset.py` 一键重算）。

**核心概念覆盖率 77.5%（31/40），缺失 9 个**：等式的性质、代入消元法、
加减消元法、全等三角形的判定、公式法、通分、待定系数法、相似比、位似。

缺失集中在**方法类/性质类概念**（「配方法」「通分」「消元法」），
而 K12-KGraph 主要收录名词性概念。其中 7 个存在可桥接的近似节点：

| 缺失概念 | 图谱中可桥接的近似节点 |
|---|---|
| 等式的性质 | 等式的性质1、等式的性质2（七上） |
| 代入消元法 / 加减消元法 | 消元法、代入法（七下） |
| 全等三角形的判定 | 全等三角形、SSS判定法（八上） |
| 公式法 | 公式法（求根公式）（九上） |
| 通分 | 分式的通分（八上） |
| 相似比 | 相似三角形的性质：对应线段成比例（九下） |

完全无近似的仅 2 个：**待定系数法、位似**。

**影响与对策**：

1. 缺失概念不会造成误判——检索返回空或近似节点，年级查表随之返回 `NE`，
   不会凭空判超纲（规则层对无法判定一律保守返回 NE）。
2. 缺口清单是 Phase 1 用 Hy3 补充 Tier 1 条目的**直接输入**，按表逐条补齐。
3. 另有**反向偏差**：图谱把「代数式」挂在八下（二次根式章节），
   而人教版七上第二章即以「用字母表示数」引入。若直接判超纲会造成
   系统性假阳性。已通过 `src/edu_eval/kb/grade_exempt.json` 豁免，
   每条豁免均附教材依据，规则层会输出 `R-GRADE-EXEMPT` 留痕供审计。

## 5.1 Tier 2 断言的生成与校验流水线（P1-1）

断言由 Hy3 生成，但**生成 ≠ 可信**。每条断言必须过校验才能进入 G0：

```text
Hy3 生成候选断言（严格 JSON）
        │
        ├─ sympy 能算的（恒等式 / 公式 / 方程求根）── 真算
        │     算对 → verified ｜ 找出反例 → quarantined ｜ 算不了 → unverified
        │
        └─ sympy 算不了的（结构性 / 性质类断言）
              └─ 一致性复核：换独立提示让 Hy3 重新推导并尝试证伪
                    判对 → verified ｜ 判错 → quarantined ｜ 没返回结论 → unverified
```

三态语义（务必分清，混淆会造成系统性误判）：

| 状态 | 含义 | 对 G0 的影响 |
|---|---|---|
| `verified` | 通过确定性校验 | 参与判定 |
| `unverified` | **未判定**（能力边界，不是通过） | 返回 NE |
| `quarantined` | 校验发现错误，**断言其错误** | 隔离，永不参与 |

两条设计红线（均来自实测教训）：

1. **「没拿到复核结论」必须记为 `unverified`，绝不能记为 `quarantined`。**
   前者只是承认判定不了，后者是断言该知识有错——首轮实现把缺结论当判错，
   一次性误杀整批 10 条正确断言。
2. **错误断言必须留痕而非静默丢弃。** 被 quarantined 的条目保留在文件中，
   可审计"模型错在哪"，也是后续优化生成提示的输入。

复核采用分批（≤6 条/批）+ 覆盖率不足自动重试，并对模型偶发的
1-based `idx` 偏移做纠正。

一键重建：

```bash
set -a; source .env; set +a
PYTHONPATH=src python scripts/build_tier2_assertions.py --all \
  --out data/assertions --summary data/assertions/summary.json
```
